## Working with github

- if agent sandbox github token is invalid use `zsh` for `gh` cli
- for every session create new branch if not said otherwise. I can ask you to make changes in the current branch
- branch should reflect type of changes: `fix`, `feat`, `docs`, `chore`, `refactor`, `test`, `style`, `perf`. Do not use `codex` branch.
- If you commiting changes add yourself as contributor to commit message with model name, version, effort.

## Before starting to work

- after exploring issue or my prompt, ask me for questions if you have any.
- provide short but concise plan of action. Don't spare technical details.
