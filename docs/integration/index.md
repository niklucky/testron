# Bring your Playwright tests to Testron

Write tests in your editor, keep them in Git, and publish them to your team's
Testron project. Stable IDs connect each local test to its revision history.
Typed suite references let you organize tests where you write them.

Start with the quickstart. The Playwright guide explains annotations, while the
synchronization guide covers conflicts and source downloads. The CLI reference
and agent guide are also bundled with the CLI, so they are available offline.

Portable smoke tests can be edited and run in Testron or pulled for local/CI use.
Complex repository tests are published for QA visibility and cannot run remotely.
A Playwright reporter connects local/CI outcomes to test history. The authoring
skill is available at https://testron.dev/agents/SKILL.md.
